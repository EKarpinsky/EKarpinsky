# Eli Karpinsky

Software leader in Toronto. Case studies and writing at [karpinsky.io](https://karpinsky.io).

- [screen-pinyin](https://github.com/EKarpinsky/screen-pinyin): select Chinese text anywhere on screen and get pinyin, definitions and flashcards. OCR, dictionary and search all run locally. Electron, Tesseract, SQLite FTS5.
- [LeaguesMap](https://github.com/EKarpinsky/LeaguesMap): an interactive map and task tracker for an Old School RuneScape league, with RuneLite progress import. Live at [leagues-map.karpinsky.io](https://leagues-map.karpinsky.io). React, TypeScript, Leaflet.
- [runelite-level-up-table](https://github.com/EKarpinsky/runelite-level-up-table): a RuneLite plugin that shows what each skill level unlocks, parsed live from the OSRS Wiki. Java.
- [karpinsky-io](https://github.com/EKarpinsky/karpinsky-io): the source for karpinsky.io. SvelteKit, prerendered, on Cloudflare Pages.
